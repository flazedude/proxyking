ProxyKing 0.3.2

- Activity now offers optional usage logging for observed app names, destinations, TCP/UDP and Proxy/Direct routes. The switch works while connected, defaults off and remembers its setting. Recent history stays in memory and can be cleared.
- Updates check JACK-PC LAN, GPD-PC LAN and GitHub, select the newest available release, and prefer matching LAN downloads. Installer signatures and signed versions are verified before proxy cleanup and installation.
- JACK-PC hosts the installer at `http://192.168.2.76:17845/proxyking/ProxyKing-Setup.exe`, alongside HappyCheats' separate download namespace. GitHub remains available when LAN hosts are offline. GPD-PC requires its server route and mirror setup before its LAN endpoint is available.

Existing 0.3.0–0.3.1 installations receive this update through GitHub. Use **Check for updates**, then **Install 0.3.2 and restart**. Installation disconnects the proxy and retains account-encrypted profiles; it never reconnects automatically.

Usage logging samples active connections, so very short connections can be missed and app attribution can be unavailable. An observed route does not prove successful delivery. No page URLs, traffic contents or proxy credentials are logged.

Validation: 177 frontend tests, 25 native tests, production build, formatting and strict Clippy; real-engine loopback routing/usage checks; LAN server isolation and download checks; public-key mirror verification and tamper/signed-version rejection. Elevated live TUN traffic, external provider connections and an installed-app upgrade were not exercised.
